# KeyOverlay

Klavyede bastığınız belirli tuşları ekranda gösteren hafif bir overlay.

## Özellikler

- Hafif kod
- Gelişime açık
- Herkese açık ve ücretsiz

## Kurulum

Python 3.x gerekli.

    git clone https://github.com/delloRkicR/KeyOverlay.git
    cd KeyOverlay
    pip install -r requirements.txt

## Kullanım

    python key_overlay.py

## Exe olarak derleme

    pip install pyinstaller
    pyinstaller KeyOverlay.spec

Çıktı `dist/` klasöründe oluşur. Hazır exe için Releases sayfasına bakın.
